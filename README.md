## Quick Deployment Guide

1. Extract `QawserQayoom_GitHub_Repo_Full_Structure.zip`.
2. Open [`https://github.com/G-sahaab/QawserQayoom`](https://github.com/G-sahaab/QawserQayoom) -> click **Add file** -> **Upload files**.
3. Drag and drop all extracted files and folders (`index.html`, `CNAME`, `.nojekyll`, `404.html`, `robots.txt`, `sitemap.xml`, `README.md`, `cv/`, and `assets/`) into the upload area and click **Commit changes**.
4. In **Settings -> Pages**, set Branch to `main` (`/root`) and verify custom domain `qawserqayoom.cv`.
